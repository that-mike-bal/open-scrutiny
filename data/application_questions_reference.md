# ICANN 2026 New gTLD Program — Application Questions Reference

> **Source:** ICANN New gTLD Program: 2026 Round Applicant Guidebook, V1-2025.12.16, Appendix 1 (Pages 248–337)  
> **Purpose:** LLM-friendly structured reference mapping all 225 application questions to their entity scope, question type, applicability, and public posting status.

---

## How to Read This Document

Each question entry includes:
- **Q#** — The ICANN question number
- **TAMS Section** — Where it lives in the TLD Application Management System
- **Entity** — The legal/organizational subject the question is *about* (e.g., Applying Entity, Primary User, Financial Institution)
- **Public** — Whether the answer is publicly posted (`Yes`, `No`, `Partial`)
- **Applicability** — Which application types or entity profiles must answer this question
- **Topic** — Brief description of what is being asked

### Applicability Key
- **ALL** = Required of all applying entities and application types
- **Community** = Only Community gTLD applicants
- **Geographic** = Only Geographic Name applicants
- **Reserved** = Only Reserved Name applicants
- **Brand** = Only .Brand TLD applicants or Code of Conduct exemption seekers
- **Variant** = Only applicants also applying for a variant string
- **Gov Profile** = Entities assigned the Government financial profile
- **Registry Operator Profile** = Entities assigned the Registry Operator financial profile
- **Top 25 Profile** = Entities assigned the Top 25 Stock Exchange financial profile
- **Standard Profile** = Entities assigned the Standard financial profile
- **Community + Brand** = Applies to both Community and Brand applicants
- **RVC** = Only entities wishing to submit Registry Voluntary Commitments
- **Conditional** = Triggered by a prior answer (noted inline)

### Safeguard Group Classification Questions

| Q# | Safeguard Group | Public | Topic | Outcome if "Yes" |

| 166 | Group 2 | Yes | Would people generally think this TLD will be used by entities requiring strict licensing or accreditation? | Classified as Safeguard Group 2 — Highly-Regulated Sectors/Closed Entry; requires Safeguards 1–8 |
| 167 | Group 2 | Yes | Would most people think domains in this TLD are used for activities requiring regular government reporting and oversight? | Classified as Safeguard Group 2; requires Safeguards 1–8 |
| 168 | Group 3 | Yes | Could people reasonably believe domains in this TLD will cause or lead to harassment, harm, aggression, complaints, criticism, distress, or embarrassment? | Classified as Safeguard Group 3 — Potential for Cyber Bullying/Harassment; requires Safeguards 1–9 |
| 169 | Group 4 | Yes | Would most people think this TLD is used for something usually done by governments? | Classified as Safeguard Group 4 — Inherently Governmental Functions; requires Safeguards 1–8 and Safeguard 10 |

### Financial Profile Determination Logic (Q189–191)

```
Q189: Governmental entity / IGO / INGO?
  ├─ YES → Government Profile (Set 15: Q192–194)
  └─ NO → Q190

Q190: Current registry operator or affiliate?
  ├─ YES → Registry Operator Profile (Set 16: Q195–201)
  └─ NO → Q191

Q191: Publicly traded on Top 25 exchange or affiliate?
  ├─ YES → Top 25 Profile (Set 17: Q202–207)
  └─ NO → Standard Profile (Set 18: Q208–219)

Note: If multiple profile categories apply, the FIRST qualifying profile is assigned
(e.g., Registry Operator profile takes precedence over Top 25).
```
